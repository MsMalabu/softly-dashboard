Choose which copy should be used first. Do not use both buttons without backups.

Your data, your choice

Softly saves a local copy in this browser. After you sign in and enable Softly Cloud, changes can also be saved to your private Supabase record. Google Calendar remains manual.

Export regularly. Import on another device to transfer your data manually. Import replaces current dashboard data.

Google Calendar

Each scheduled event offers an “Add to Google Calendar” link. It opens a prefilled Google event for you to save. Google events won't automatically appear here, and editing either copy won't update the other.

Install / save this dashboard

Keep the HTML file somewhere safe. Open it in Chrome or Edge and bookmark it. Your data is tied to the browser and file origin; moving or renaming the file may make previous data inaccessible. Export a backup before moving it.
